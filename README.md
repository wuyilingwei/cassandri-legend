# 卡桑德里传说

浏览器文字冒险 RPG。移植自同名 Python 终端游戏 3.0 版，现为 5.0（数值平衡扩充版）。

在线游玩：<https://wuyilingwei.github.io/cassandri-legend/>

- 4 种祝福路线 × 20 回合战斗 × 随机装备
- 9 个结局，其中一个藏得很深
- 纯静态单文件，无任何依赖
- 存档系统：自动存档 + 3 个手动槽位，随时保存/读取

## 5.0 数值平衡与词表扩充

1. 战士吸血 6%→8%、每胜攻击力 ×1.22；天使每胜血量 ×1.24、每 20 点血量增伤 3%→4%
2. 勇者初始攻击力 +20→+25、暴击率 +10%→12%、暴击伤害 +30%→40%，每胜暴击率增幅 5–8%→5–11%、暴击伤害 ×1.2→×1.28
3. 隐者每胜闪避率增幅 3–6%→4–7%，溢出闪避每 10% 增伤 5%→6%
4. 普通敌人攻击力与血量新增 ±35% 随机浮动（魔王与隐藏路线敌人数值不变）
5. 装备与怪物词表大幅扩充
6. 隐藏路线拒绝迎战台词重写

## 4.0 玩法变更

1. 隐藏路线触发方式重做：魔王威压掉装备后拒绝迎战累计 3 次触发
2. 闪避（CRT）装备权重调整

## 网页版特性

1. 全面网页化，浏览器直接游玩，移动端适配
2. 像素风界面重制：实时状态栏、固定高度消息面板、CRT 扫描线
3. 装备默认按序自动入槽；装备面板变更预览
4. 存档系统：自动存档 + 3 个手动 save 槽，SL 界面
5. 设置面板（右上角）：速度 / 跳过动画 / 扫描线随时可调，附重看教程入口
6. 教程仅首次询问，此后新开局直接进入祝福选择
7. 存档与设置相关确认操作统一为页内像素风弹窗
8. 修复原版魔王战前无装备时崩溃的问题
9. 结局与隐藏内容与原版一致（共 9 个结局）
10. 4.0 存档因数值不兼容已随本次更新清理，无法迁移
