# 卡桑德里传说

浏览器文字冒险 RPG。移植自同名 Python 终端游戏 3.0 版，现为 4.0。

在线游玩：<https://wuyilingwei.github.io/cassandri-legend/>

- 4 种祝福路线 × 20 回合战斗 × 随机装备
- 9 个结局，其中一个藏得很深
- 纯静态单文件，无任何依赖
- 存档系统：自动存档 + 3 个手动槽位，随时保存/读取

## 4.0 变更

网页版：

1. 全面网页化，浏览器直接游玩，移动端适配
2. 像素风界面重制：实时状态栏、固定高度消息面板、CRT 扫描线
3. 装备默认按序自动入槽；装备面板变更预览
4. 存档系统：自动存档 + 3 个手动 save 槽，SL 界面
5. 设置面板（右上角）：速度 / 跳过动画 / 扫描线随时可调
6. 修复原版魔王战前无装备时崩溃的问题
7. 游戏机制与台词与 3.0 一致（含全部结局与隐藏内容）

玩法变更：

1. 隐藏路线触发方式重做：魔王威压掉装备后拒绝迎战累计 3 次触发
2. 闪避（CRT）装备权重调整
