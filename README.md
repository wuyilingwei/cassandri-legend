# 卡桑德里传说

浏览器文字冒险 RPG。基于用户提供的《卡桑德里传说》6.5 源文件发布为纯静态网页。

在线游玩：<https://wuyilingwei.github.io/cassandri-legend/>

- 4 种职业 × 4 种祝福 × 20 波随机战斗
- 随机装备、元素套装、装备与敌人特性
- 能量必杀、防御、自动战斗和最终决战快速模拟
- 金币商城、永久强化、第五装备槽与难度系统
- 浏览器本地保存魔王之眼、它之血珠、金币和商城进度
- 像素终端 UI、左右对阵战斗场景与动态生命/护盾条
- 战利品装备对比：按输出与生存分别给出替换建议和属性变化量

## 6.5 版本

1. 玩法更新为 6.5 完整源文件：职业、祝福、装备、敌人、战斗和结局逻辑均以其为准
2. 新增元素套装、敌人特性、自动战斗、能量必杀技与最终决战快速模拟
3. 新增金币商城、潘多拉之盒、永久强化和第五装备槽
4. 新增它之血珠难度机制；高难度会加强敌人并施加额外限制
5. 进度使用独立的浏览器本地存储键 `kasandri6_save`。5.0 存档不会被删除，但与 6.5 玩法不兼容，因此不会迁移或读取；升级后从新进度开始
6. 恢复像素终端交互界面；战斗时显示勇者与敌人的左右对阵、血条、护盾和即时战斗反馈
7. 掉落装备会显示与当前构筑的对比：输出和生存的预计变化、套装/特性变化，以及推荐或不推荐的换装结论

## 运行

无需安装依赖。直接用浏览器打开 [`index.html`](index.html) 即可游玩。
